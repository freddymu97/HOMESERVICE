# Imágenes de HomeService

Cada servicio usa un par de imágenes responsivas desde esta carpeta: una vertical para las tarjetas en escritorio y otra horizontal para móvil. La web selecciona automáticamente la variante según el ancho de pantalla y mantiene el texto alternativo descriptivo.

Los pares `destape-desagues` y `griferia-sanitarios` llegaron con la orientación contraria a su sufijo. La implementación los asigna por su proporción real para conservar el encuadre correcto sin alterar los archivos originales.

El archivo `homeservice-logo-blanco.png` se usa en la cabecera sobre fondos oscuros.

Estas imágenes son representativas del servicio. No deben presentarse como trabajos realizados, casos reales o clientes si no existe evidencia verificable.
